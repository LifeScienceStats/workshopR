2.4 Merging and merge conflict

  • Merging:
    • combines changes from one branch into another
      • typically integrating a feature branch into main
      • but it could also be a fix within a branch
  • Merge conflict:
    • Git cannot automatically combine changes because the same part of a file was edited differently in both branches
  • Resolving conflicts:
    • manually editing the conflicting files, keeping the desired changes, then staging and committing the resolution

4 New SOP

4.1 Roles and responsibilities

  • Repository Manager

    • creates and configures repositories

    • manages access & permissions

    • ensures that the main represents the current approved version

  • Contributor

    • develops changes, submitting for review via pull request

    • addresses review comments, resolves merge conflicts affecting their branch

    • maintains local repository

  • Reviewer

    • reveiw of submitted code (proposed change is correct and appropriate)

    • requests changes or clarification where required, and

    • approves the pull request
